# COMPETITIVE_PROGRAMMING

A collection of **Competitive Programming and Data Structures & Algorithms programs completed as part of my college coursework and practical assignments**.

This repository contains Java implementations of various problems, algorithms, data structures, and programming exercises covered during the course.

## 📚 Topics Covered

The repository currently includes programs related to:

* Arrays
* Searching
* Sorting
* Hashing
* Linked Lists
* Trees
* Graphs
* BFS & DFS
* Shortest Path Algorithms
* Minimum Spanning Trees
* Dynamic Programming
* Greedy Algorithms
* Recursion
* Address Calculation
* Data Structure Operations
* Problem-solving exercises
